# README visual assets

These original SVG illustrations were authored locally for AgentOS. No stock
artwork, remote fonts, image-generation service or paid asset was used.

| Asset                  | Purpose                                                  | Canvas     |
| ---------------------- | -------------------------------------------------------- | ---------- |
| `agentos-hero.svg`     | Wordmark and conceptual agent-orchestration illustration | 1600 × 650 |
| `agentos-profiles.svg` | Consistent Developer, Creator and Student visual cards   | 1200 × 230 |
| `divider.svg`          | Decorative cyan-to-violet section divider                | 1200 × 20  |

All files have scalable view boxes, system font fallbacks, and no scripts,
external resources or embedded bitmap data. Meaningful illustrations have SVG
titles/descriptions and README alt text. Essential information is repeated as
native Markdown so it remains readable on narrow screens.

The hero is a **concept illustration**, not a capture of Mission Control.
No application screenshots are currently tracked. Useful future captures are:

1. Mission Control dashboard with the explicit offline-demo label and role selector.
2. Developer task graph and tested diff/report awaiting human review.
3. Creator sourced script and locally rendered thumbnail review.
4. Student source evidence, notes, quiz and separate answer key.

Use actual application captures, remove sensitive local paths/data, and state
the execution mode. Do not turn illustrations into purported screenshots.
