# Bundled thumbnail font

Noto Sans, unmodified from google/fonts commit
51303ca9e8ac9dcea7b12d307ba568fd0e6fcfca,
`ofl/notosans/NotoSans[wdth,wght].ttf`. License: [OFL.txt](OFL.txt).

Renderer v1 supports printable ASCII (U+0020–U+007E) only; other glyphs fail
explicitly. Each frozen rendering receipt includes the font file SHA-256:
`bfb7bb691513f12e734dc346c03a03f784912432d7e3fa8e56efcf906fe86b3d`.
